# Limitaciones

Este documento existe para que nadie use el simulador más allá de lo que hace. Cada punto lleva el
identificador que lo declara en `src/validation/limitations.ts` (la suite exige que ambos coincidan).
Cuando una limitación se resuelve, se borra de los dos sitios en el mismo cambio.

## Estado del proyecto

- **Todavía no hay imagen** (`no-image-yet`): la fase 0 deja los cimientos (repositorio, guardas,
  documentos rectores y base de conocimiento). La formación de imagen llega en la fase 1
  (`docs/ROADMAP.md`).
